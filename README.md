# Acing the Data Science Interview

Materials from a talk to the UNC Data Science Program, 2026.

The thesis: AI has raised the floor for everyone's application materials, so what stands out now is verifiable evidence of your own thinking. Build things you can explain.

## What's in this repo

| Path | What it is |
|---|---|
| [`handout/checklist.md`](handout/checklist.md) | One-page interview-prep checklist: basics, GitHub, STAR, technical prep, standing out |
| [`handout/model-answers.md`](handout/model-answers.md) | 19 practice questions with a 30-second answer and a deeper follow-up answer each, plus STAR scaffolds for the behavioral questions |
| [`examples/sample-project-README.md`](examples/sample-project-README.md) | A fill-in-the-blank README for a portfolio project, with a suggested repo layout |

## How to use these materials

1. Start with the checklist and tick off what you already have.
2. Practice the questions in `model-answers.md` out loud. Say the 30-second version first, then the deeper one, and stop reading the answer as soon as you can say it yourself.
3. Copy the sample project README into one of your own repos and replace every bracketed placeholder with your real work.
4. For the behavioral questions, write your own stories. The scaffolds show structure; they are not scripts.

## A note on AI use

These materials were drafted with help from an AI assistant (Claude) and are meant as a starting point. All numbers in examples are illustrative placeholders, not real results. Check anything you rely on, and use only numbers you can defend in an interview.
